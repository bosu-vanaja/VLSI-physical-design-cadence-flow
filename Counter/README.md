# Counter Physical Design

RTL-to-GDSII implementation of 8-bit counter using Cadence flow including floorplanning, placement, CTS, routing, STA, and DRC/LVS verification.

## Features
- 8-bit synchronous counter
- Optimized placement and routing
- Timing analysis and violation fixing

## Physical Design Flow
- RTL Design
- Floorplanning
- Placement
- Clock Tree Synthesis (CTS)
- Routing
- Static Timing Analysis (STA)
- DRC/LVS Verification

## Tools Used
- Cadence Innovus
- Verilog HDL
