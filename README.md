# VLSI Physical Design Implementation (Cadence Flow)

## Overview
Implemented multiple digital designs from RTL to GDSII using Cadence physical design flow.

## Implemented Modules
- 8-bit Counter
- LFSR
- Synchronous FIFO
- FSM
- Register Bank
- 3-Stage Pipeline

## Physical Design Stages
- Floorplanning
- Placement
- Clock Tree Synthesis (CTS)
- Routing
- Static Timing Analysis (STA)
- DRC/LVS Verification
- Power and Parasitic Analysis

## Tools Used
- Cadence Innovus
- Verilog HDL

## Highlights
- Resolved setup/hold violations
- Optimized congestion and routing
- Verified layout correctness through DRC/LVS
