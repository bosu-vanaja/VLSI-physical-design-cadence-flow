# 3-Stage Pipeline Physical Design

RTL-to-GDSII implementation of a 3-stage pipelined architecture using Cadence flow including floorplanning, placement, CTS, routing, STA, and DRC/LVS verification.

## Features
- 3-stage pipelined data processing
- Improved performance through pipelining
- Optimized clock and routing network

## Physical Design Flow
- RTL Design
- Floorplanning
- Placement
- Clock Tree Synthesis (CTS)
- Routing
- Static Timing Analysis (STA)
- DRC/LVS Verification

## Tools Used
- Cadence Innovus
- Verilog HDL
