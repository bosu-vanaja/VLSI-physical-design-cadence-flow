# Register Bank Physical Design

RTL-to-GDSII implementation of Register Bank using Cadence flow including floorplanning, placement, CTS, routing, STA, and DRC/LVS verification.

## Features
- Multi-register data storage architecture
- Efficient read/write operations
- Optimized timing and routing implementation

## Physical Design Flow
- RTL Design
- Floorplanning
- Placement
- Clock Tree Synthesis (CTS)
- Routing
- Static Timing Analysis (STA)
- DRC/LVS Verification

## Tools Used
- Cadence Innovus
- Verilog HDL
