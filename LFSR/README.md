# LFSR Physical Design

RTL-to-GDSII implementation of Linear Feedback Shift Register (LFSR) using Cadence flow including floorplanning, placement, CTS, routing, STA, and DRC/LVS verification.

## Features
- Pseudo-random sequence generation
- Efficient clock distribution
- Optimized routing and timing

## Physical Design Flow
- RTL Design
- Floorplanning
- Placement
- Clock Tree Synthesis (CTS)
- Routing
- Static Timing Analysis (STA)
- DRC/LVS Verification

## Tools Used
- Cadence Innovus
- Verilog HDL
