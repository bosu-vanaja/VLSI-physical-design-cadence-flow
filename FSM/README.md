# FSM Physical Design

RTL-to-GDSII implementation of Finite State Machine (FSM) using Cadence flow including floorplanning, placement, CTS, routing, STA, and DRC/LVS verification.

## Features
- State transition based control logic
- Optimized placement and routing
- Timing-aware physical design implementation

## Physical Design Flow
- RTL Design
- Floorplanning
- Placement
- Clock Tree Synthesis (CTS)
- Routing
- Static Timing Analysis (STA)
- DRC/LVS Verification

## Tools Used
- Cadence Innovus
- Verilog HDL
